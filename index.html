About Me

Halo! Saya Adam, 29 tahun. Saat ini saya berkarya sebagai Fullstack Developer (Spesialis Backend) di Universitas Sebelas Maret (UNS).

Perjalanan karir saya dimulai di dunia startup bersama Takodam sebagai Software Engineer selama lebih dari 4 tahun. Di sana, saya belajar banyak tentang agility dan rapid development. Transisi ke sektor edukasi telah membuka wawasan baru saya tentang pentingnya stabilitas dan skalabilitas dalam sistem berskala besar.

Ketertarikan teknis saya saat ini berpusat pada Big Data (Hadoop/Spark) dan merancang API Gateway yang efisien. Di luar koding, saya adalah seorang ayah yang mencoba menyeimbangkan logika kode dengan logika 'jokes bapak-bapak'.
